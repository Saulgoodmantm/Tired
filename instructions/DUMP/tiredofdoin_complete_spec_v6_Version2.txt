# 🔒 GLOBAL SYSTEM RULES

## Rule 1: Permission-First Architecture
Every request must: 
1. Identify the user (session/token/guest)
2. Determine their role
3. Check permission for requested resource
4. Allow OR deny with logging

```
Request → Identify User → Check Role → Verify Permission → Proceed/Deny
```

**Edge Cases:**
- Expired session during action → Re-authenticate, retry
- Role changed while logged in → Immediate permission refresh
- Shared link access → Validate link token separately
- API key access → Different permission path

## Rule 2: Auth Gate on All Protected Routes
Every navigation to protected pages must route through `/auth`:

```
User clicks /dashboard
    ↓
Redirect to /auth? next=/dashboard
    ↓
Validate session + role
    ↓
Success → Redirect to /dashboard
Failure → Show login with next= preserved
```

## Rule 3: Data Classification

### Public Data (Never Encrypted, Cacheable)
| Data | Cache Duration |
|------|----------------|
| Public gallery thumbnails | 7 days |
| Pricing information | 1 hour |
| Testimonials | 1 day |
| Homepage content | 1 day |

### Private Data (Always Encrypted - AES-256-GCM)
- User credentials
- Session tokens
- Payment data (Stripe handles)
- RAW photographs
- Private galleries
- Contracts
- Messages
- Booking details

## Rule 4: RAW vs Edited Image Separation

### RAW Track
- Original file (CR2, NEF, ARW, DNG)
- Encrypted at rest
- Never publicly accessible
- Stored forever
- Reserved for:  legal proof, AI training, ownership disputes

### Edited Track
- Optimized JPG/WebP
- Multiple sizes (full, web, mobile, thumb)
- Optional watermark
- Public or private based on gallery settings

### Storage Structure
```
R2 Bucket:  tiredproduction
├── /raw/{gallery_id}/{image_id}/original.*
├── /edited/{gallery_id}/{image_id}/
│   ├── full.jpg
│   ├── full_watermarked.jpg
│   ├── web.jpg (1920px)
│   ├── mobile.jpg (1080px)
│   └── thumb.jpg (400px)
└── /temp/{upload_session}/
```

## Rule 5: No Static UI
Every visible element must have motion:
- **Ambient**:  Subtle gradients, glow pulsing, parallax
- **Interactive**: Hover states, click feedback, focus rings
- **State**:  Loading shimmer, success animations, error shake
- **Navigation**: Page transitions, modal animations, menu sweeps

**Performance Rules:**
- All animations 60fps
- Use CSS transforms only
- Respect `prefers-reduced-motion`
- Durations under 500ms for interactions

```
1. User enters email
       │
       ▼

       ▼
4. Store OTP in database:

```

### OTP Generation (PHP)
```php
function generateOTP(): string {
    // Removed ambiguous characters:  0, O, I, 1, L
    $chars = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
    $otp = '';
    for ($i = 0; $i < 6; $i++) {
        $otp .= $chars[random_int(0, strlen($chars) - 1)];
    }
    return $otp;
}
```

## Session Management

### Session Creation (PHP)
```php
function createSession(User $user, Request $request): Session {
    $sessionToken = bin2hex(random_bytes(32));
    $fingerprint = generateDeviceFingerprint($request);
    $expiresAt = time() + (30 * 24 * 60 * 60); // 30 days
    
    $session = Session::create([
        'user_id' => $user->id,
        'token_hash' => password_hash($sessionToken, PASSWORD_DEFAULT),
        'device_fingerprint' => $fingerprint,
        'ip_address' => $request->ip(),
        'user_agent' => $request->userAgent(),
        'expires_at' => date('Y-m-d H: i:s', $expiresAt)
    ]);
    
    setcookie('session', $sessionToken, [
        'expires' => $expiresAt,
        'path' => '/',
        'domain' => 'tiredofdointm.com',
        'secure' => true,
        'httponly' => true,
        'samesite' => 'Lax'
    ]);
    
    return $session;
}

function generateDeviceFingerprint(Request $request): string {
    $components = [
        $request->header('User-Agent'),
        $request->header('Accept-Language'),
        $request->header('Accept-Encoding'),
    ];
    
    return substr(hash('sha256', implode('|', $components)), 0, 32);
}
```

### Session Validation (Every Request)
```php
function validateSession(Request $request): ?User {
    $token = $_COOKIE['session'] ?? null;
    if (!$token) return null;
    
    $sessions = Session::where('expires_at', '>', date('Y-m-d H: i:s'))->get();
    
    foreach ($sessions as $session) {
        if (password_verify($token, $session->token_hash)) {
            // Validate fingerprint (optional)
            $currentFingerprint = generateDeviceFingerprint($request);
            if ($session->device_fingerprint !== $currentFingerprint) {
                logSecurityEvent('fingerprint_mismatch', $session->user_id);
            }
            
            return User::find($session->user_id);
        }
    }
    
    return null;
}
```

## JavaScript Implementation
```javascript
// gate.js
class GateSystem {
    constructor() {
        this.overlay = document.getElementById('gate-overlay');
        this.input = document.getElementById('gate-input');
        this.isUnlocked = this.checkGateCookie();
        
        if (!this.isUnlocked) {
            this.init();
        }
    }
    
    checkGateCookie() {
        const cookie = document.cookie
            .split('; ')
            .find(row => row.startsWith('gate_pass='));
        
        if (!cookie) return false;
        
        // Cookie exists, verify with server
        return true; // Server validates on each request
    }
    
    init() {
        // Show gate after delay
        setTimeout(() => {
            this.overlay.classList.add('active');
        }, 100);
        
        // Listen for input
        this.input.addEventListener('input', (e) => {
            if (e.target.value.length >= 2) {
                this.validate(e.target.value);
            }
        });
        
        this.input.addEventListener('keypress', (e) => {
            if (e.key === 'Enter') {
                this. validate(this.input.value);
            }
        });
    }
    
    async validate(password) {
        try {
            const response = await fetch('/api/gate/validate', {
                method: 'POST',
                headers: {
                    'Content-Type':  'application/json',
                    'X-CSRF-Token': document.querySelector('meta[name="csrf-token"]').content
                },
                body: JSON.stringify({ password })
            });
            
            if (response. ok) {
                this.unlock();
            } else {
                this.showError();
            }
        } catch (error) {
            console.error('Gate validation failed:', error);
            this.showError();
        }
    }
    
    unlock() {
        this.input.classList.add('success');
        
        setTimeout(() => {
            this.overlay.classList.remove('active');
            
            setTimeout(() => {
                this.overlay.remove();
            }, 500);
        }, 300);
    }
    
    showError() {
        this.input.classList.add('error');
        this.input.value = '';
        
        setTimeout(() => {
            this.input. classList.remove('error');
            this.input.focus();
        }, 500);
    }
}

document.addEventListener('DOMContentLoaded', () => {
    new GateSystem();
});
```

## Server-Side Validation (PHP)
```php
// api/gate/validate.php
function validateGate(Request $request): Response {
    $password = $request->input('password');
    
    // Constant-time comparison to prevent timing attacks
    $expected = getenv('GATE_PASSWORD'); // "67"
    
    if (! hash_equals($expected, $password)) {
        return response()->json(['error' => 'Invalid'], 401);
    }
    
    // Create HMAC-signed cookie
    $timestamp = time();
    $expires = $timestamp + (30 * 24 * 60 * 60); // 30 days
    $payload = "{$timestamp}:{$expires}";
    $signature = hash_hmac('sha256', $payload, getenv('GATE_SECRET'));
    
    setcookie('gate_pass', "{$payload}:{$signature}", [
        'expires' => $expires,
        'path' => '/',
        'domain' => 'tiredofdointm. com',
        'secure' => true,
        'httponly' => true,
        'samesite' => 'Lax'
    ]);
    
    return response()->json(['success' => true]);
}

// Middleware to check gate
function gateMiddleware(Request $request, Closure $next): Response {
    $cookie = $_COOKIE['gate_pass'] ??  null;
    
    if (! $cookie) {
        // Allow gate page itself
        if ($request->path() === '/' || str_starts_with($request->path(), '/api/gate')) {
            return $next($request);
        }
        return redirect('/');
    }
    
    // Validate cookie signature
    $parts = explode(':', $cookie);
    if (count($parts) !== 3) {
        setcookie('gate_pass', '', time() - 3600, '/');
        return redirect('/');
    }
    
    [$timestamp, $expires, $signature] = $parts;
    
    // Check expiration
    if (time() > (int)$expires) {
        setcookie('gate_pass', '', time() - 3600, '/');
        return redirect('/');
    }
    
    // Verify signature
    $expectedSignature = hash_hmac('sha256', "{$timestamp}:{$expires}", getenv('GATE_SECRET'));
    if (!hash_equals($expectedSignature, $signature)) {
        setcookie('gate_pass', '', time() - 3600, '/');
        return redirect('/');
    }
    
    return $next($request);
}
```

## Permission Middleware (PHP)
```php
class RoleMiddleware {
    public function handle(Request $request, Closure $next, string $permission): Response {
        $user = $request->user();
        
        // Guest handling
        if (!$user) {
            if ($permission === 'view_public') {
                return $next($request);
            }
            
            $nextUrl = urlencode($request->fullUrl());
            return redirect("/login?next={$nextUrl}");
        }
        
        $role = Role::find($user->role_id);
        $permissions = $role->permissions;
        
        // Admin wildcard
        if (isset($permissions['*']) && $permissions['*']) {
            return $next($request);
        }
        
        // Check specific permission
        if (isset($permissions[$permission]) && $permissions[$permission]) {
            return $next($request);
        }
        
        // Permission denied
        Logger::security('permission_denied', [
            'user_id' => $user->id,
            'permission' => $permission,
            'route' => $request->path()
        ]);
        
        return response()->view('errors/403', [], 403);
    }
}
```
